# Contributing to realtime-trains-py and realtime-trains-rs

## Guidelines:

If you would like to contribute to *realtime-trains-py* or *realtime-trains-rs* by submitting a pull request, please ensure that your local copy of the repository is **thoroughly reviewed** and **free of any sensitive or personal information**. This includes, but is not limited to, usernames, passwords, API keys, or any other credentials that might compromise your security or the integrity of the repository.  

Keep in mind that **all pull requests are public** and can be viewed by anyone on the internet once submitted. To protect your privacy and maintain the security of your systems, double-check your code and configuration files before making any changes public.  
Not all submitted pull requests will be merged into the main branch. Any pull requests that **contain sensitive or personal information will NOT be merged** into the main branch.

By following these guidelines, you help keep the project secure and maintain a professional standard for collaboration within the community. If you are unsure about the process or need assistance, feel free to check the [GitHub documentation on pull requests](https://docs.github.com/pull-requests) or reach out to the repository maintainers for guidance.

## Support

You can ask for support with your contributions in the Discord server. The roadmap contains features currently being worked on, therefore pull requests adding these features or enhancements are unlikely to be merged. 
If you'd like to provide suggestions, use the Discord sever or create an issue on this repository.

## How to Contribute

Contributing is super easy. Follow the steps below

1. Make sure you have forked and cloned the repository
2. Set up the repository as detailed in the setup guides in the wiki
3. Familiarise yourself with the above contributing guidelines
4. Create an issue on the appropriate repository with the "enhancement" tag
5. Make your changes
6.  Open a pull request - remember not all pull requests will be merged

## Bug Reporting

Please report bugs in the issues section of the repository.

## Questions

If you have any questions regarding contributing, please speak to the repository maintainers.
